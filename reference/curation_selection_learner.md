# Resolve one configured learner from the existing learner registry.

Resolve one configured learner from the existing learner registry.

## Usage

``` r
curation_selection_learner(learner_key = "logistic")
```

## Arguments

- learner_key:

  A key returned by
  [`selection_learners()`](https://barthoekstra.github.io/planscanR.screen/reference/selection_learners.md).

## Value

A `planscanR_selection_learner`.
