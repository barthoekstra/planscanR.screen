# Append a versioned acquisition setting.

Append a versioned acquisition setting.

## Usage

``` r
acquisition_storage_set(catalog, key, value, actor)
```

## Arguments

- catalog:

  Acquisition catalog.

- key:

  Setting key.

- value:

  Scalar or serializable setting value.

- actor:

  Authenticated administrator.

## Value

A list containing the new setting version.
