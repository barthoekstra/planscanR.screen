# List all priority-rule revisions for a campaign.

List all priority-rule revisions for a campaign.

## Usage

``` r
acquisition_campaign_priority_history(catalog, campaign_id)
```

## Arguments

- catalog:

  A catalog from
  [`acquisition_catalog_open()`](https://barthoekstra.github.io/planscanR.screen/reference/acquisition_catalog_open.md).

- campaign_id:

  Campaign ID.

## Value

A data frame of ordered rule revisions.
