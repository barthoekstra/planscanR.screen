# List recorded reprioritization operations.

List recorded reprioritization operations.

## Usage

``` r
acquisition_campaign_reprioritizations(catalog, campaign_id)
```

## Arguments

- catalog:

  A catalog from
  [`acquisition_catalog_open()`](https://barthoekstra.github.io/planscanR.screen/reference/acquisition_catalog_open.md).

- campaign_id:

  Campaign ID.

## Value

A data frame of reprioritization events.
