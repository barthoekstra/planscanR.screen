# List source references in the acquisition catalog.

List source references in the acquisition catalog.

## Usage

``` r
acquisition_catalog_sources(catalog, country = NULL, portal = NULL)
```

## Arguments

- catalog:

  A catalog from
  [`acquisition_catalog_open()`](https://barthoekstra.github.io/planscanR.screen/reference/acquisition_catalog_open.md).

- country:

  Optional country filter.

- portal:

  Optional portal filter.

## Value

A data frame of source references.
