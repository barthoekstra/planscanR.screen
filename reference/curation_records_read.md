# Read records from an injected provider.

Read records from an injected provider.

## Usage

``` r
curation_records_read(provider, corpus_id, countries = NULL)
```

## Arguments

- provider:

  A `planscanR_curation_records_provider`.

- corpus_id:

  Explicit corpus identity.

- countries:

  Optional country filter.

## Value

A validated record data frame.
