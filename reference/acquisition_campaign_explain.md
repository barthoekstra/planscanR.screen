# Explain campaign priority and current queue state.

Explain campaign priority and current queue state.

## Usage

``` r
acquisition_campaign_explain(catalog, campaign_id)
```

## Arguments

- catalog:

  A catalog from
  [`acquisition_catalog_open()`](https://barthoekstra.github.io/planscanR.screen/reference/acquisition_catalog_open.md).

- campaign_id:

  Campaign ID.

## Value

A data frame with energy evidence, matched rule, and queue state.
