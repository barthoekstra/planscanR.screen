# Save a curation model through the existing selection-model serializer.

Save a curation model through the existing selection-model serializer.

## Usage

``` r
curation_save_model(model, path, config = NULL)
```

## Arguments

- model:

  A `planscanR_selection_model`.

- path:

  RDS destination.

- config:

  Optional compatible curation configuration.

## Value

`path`, invisibly.
